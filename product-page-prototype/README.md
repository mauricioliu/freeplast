# Product-page prototype

Throwaway UI prototype answering: **what structure should Freeplast use for a wholesale
product-detail page?**

The three variants use the same current product copy for Caja Cosechera 3/4:

- `?variant=A` — commercial split: image and product summary first, detailed quote card below
- `?variant=B` — technical catalog: editorial hero, specification strip and dark quote rail
- `?variant=C` — quote first: compact product context followed by a guided three-step request

Use the floating arrows or the keyboard left/right arrows to switch. Form submissions are
intentionally simulated and do not send data.

Published review artifact: `https://mliu.site/freeplast/v7/?variant=A`
