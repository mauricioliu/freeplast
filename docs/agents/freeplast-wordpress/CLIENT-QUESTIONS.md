# Preguntas pendientes para Freeplast

Estas preguntas bloquean el cierre del catálogo y las reglas de cotización. No es necesario que el cliente vuelva a redactar el contenido completo.

## Catálogo 2026

1. **Traversa G2 / Romano:** En la vista general del catálogo aparece “Traversa Tipo G2”, pero la ficha individual dice “Traversa para Bins Tipo Romano”. ¿Son el mismo producto? Si lo son, ¿qué nombre debe publicarse?
2. **Pediluvio y ladrillo:** ¿Las “Bases plásticas para pediluvios” y el “Ladrillo plástico” todavía se ofrecen? Si siguen vigentes, necesitamos su ficha técnica actual, unidades por pallet y fotografía.
3. **Pallet y compra mínima:** Para cada producto, ¿las “unidades por pallet” también son la cantidad mínima de compra y el incremento obligatorio? Por ejemplo, ¿Caja Cosechera solo puede solicitarse en 70, 140, 210… unidades?
4. **Tipo Romano:** ¿Cuál es su peso? ¿Cuáles son las dimensiones del pallet armado?
5. **Caja Universal Color:** ¿Los colores blanco, rojo, amarillo, azul y verde están actualmente disponibles tanto para la caja cerrada como para la ventilada? ¿El cliente debe escoger un color al solicitar la cotización?
6. **Fotografías originales:** Favor compartir la fotografía original de mayor resolución de cada producto vigente, sin textos ni marca de agua. El PDF solo contiene imágenes compuestas dentro de cada página.
7. **Descripciones:** Prepararemos descripciones breves usando únicamente las especificaciones del catálogo 2026. ¿Puede Freeplast revisar y aprobarlas antes de publicar?

## Cotización y despacho

8. **Origen del despacho:** ¿Todos los despachos se calculan desde Camino El Arrayán 52, San Francisco de Mostazal? El sitio también menciona Santiago; ¿existe allí otra bodega u origen de despacho?
9. **Distancia:** ¿Ventas necesita la distancia de conducción de ida desde la bodega hasta la dirección del cliente, o otra medida —por ejemplo ida y vuelta, duración estimada o ruta para camión?
