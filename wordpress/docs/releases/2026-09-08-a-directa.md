### Restore ownership finding

The first isolated trial stopped **before live deployment**: default tar extraction
in Alpine mapped archive user `www-data` to **82**, whereas Apache/CLI require
numeric **33**. Minimal extraction probe reproduced **82:82 / mode 755** and the
failed write boundary. `tar --numeric-owner` preserved **33:33**; the repeated
trial passed a UID/write check and the actual complete package installation.
Backup bytes were sound; no live permissions were changed. Corrected release
backup/trial scripts are retained. This does not certify every older restore script.
